# Changelog

All notable changes to the Learning Lab repository are documented here by CRN release compatibility.

This changelog records:

* CRN release compatibility milestones
* changes to recommended Verily Workbench workspaces and data collections
* significant tutorial and documentation updates
* updates to supported datasets and tutorial paths

---

## CRN Release v5

**Status:** Current
**Validated on:** 2026-06-11
**Repo tag:** `crn-v5.0`

### Summary

Compatibility update for the Learning Lab repository aligned to CRN Release v5.

This release marks v5 as the current supported CRN release and updates the recommended Learning Lab resources, including the ASAP CRN Learning Lab Workspace V5, PMDBS single-cell RNAseq collection guidance, and PMDBS spatial RNAseq collection guidance.

### Added

* Added CRN Release v5 compatibility tracking.
* Added the recommended `ASAP CRN Learning Lab Workspace V5` workspace reference.
* Added recommended PMDBS single-cell RNAseq collection guidance for v5-compatible tutorials.
* Added support for the spatial RNAseq loading tutorial covering Visium and GeoMx datasets.
* Added preliminary support for sample notebooks in both Python and R.

### Updated

* Updated the current supported release from v4 to v5.
* Updated release compatibility documentation to include both the current v5 release and the prior v4 release.
* Updated recommended Verily Workbench workspace guidance for v5.
* Updated PMDBS dataset references for v5-compatible tutorial workflows.
* Updated tutorial compatibility notes to better distinguish single-cell RNAseq and spatial RNAseq resources.

### Changed

* Marked CRN Release v5 as the current supported release.
* Moved CRN Release v4 into archived compatibility guidance.
* Standardized release documentation around release-based workspace, data collection, and tutorial compatibility.

### Notes

* v5 should be treated as the current supported release for new users.
* v4 is retained for historical compatibility reference.
* Tutorials should only be considered supported for a release when they are listed in the release compatibility documentation.

## CRN Release v4

**Status:** Archived
**Validated on:** 2026-04-24
**Repo tag:** `crn-v4.0`

### Summary

Compatibility release for the Learning Lab repository aligned to CRN Release v4.

This release served as the previous supported baseline for PMDBS single-cell RNAseq tutorial workflows before the v5 compatibility update.

### Added

* Added support for PMDBS single-cell RNAseq tutorials against CRN Release v4.
* Added recommended Verily Workbench workspace guidance for v4.
* Added recommended data collection guidance for v4-compatible tutorials.
* Added release-based compatibility tracking for Learning Lab tutorials.

### Updated

* Updated dataset references for PMDBS cohort tutorial workflows.
* Updated recommended data collection guidance to point users to Verily Workbench resources for v4.
* Updated tutorial documentation to clarify release compatibility expectations.

### Changed

* Established v4 as the previous compatibility baseline.
* Standardized tutorial references around release-based data collections.

### Notes

* v4 is archived and retained for reference.
* New users should use the current supported release unless they specifically need v4-compatible resources.
* Tutorials should only be considered supported for v4 when they are listed in the release compatibility documentation.
