# Requesting Data Access

The CRN Cloud is a **controlled-access platform**, meaning datasets aren't available for public-download, but any researcher can request access by submitting a Data Use Application (DUA) through the CRN Cloud Explorer Platform.

This page walks through that process.

!!! tip "📚 More resources"
    - 🎥 [Navigating the CRN Cloud Explorer](https://youtu.be/NfVw8UwM6PI?si=O6S-NufoHYQQJFmR) — video walkthrough of applying for access and exploring metadata
    - 📄 [ASAP CRN Cloud User Manual](https://storage.googleapis.com/dnastack-assets/explorer/asap-public-assets/wayfinding/ASAP-CRN-Cloud-User-Manual.pdf) (PDF) — full official documentation, including detailed sample intended-use statements

Applications are submitted **per person**, so each researcher must submit their own request. However, it's a single application: once approved, you have access to **all** ASAP CRN Cloud data, not just the collection you applied from.

## Step-by-step

1. **Go to the CRN Cloud Explorer Platform at [cloud.parkinsonsroadmap.org](https://cloud.parkinsonsroadmap.org)**. No login is needed just to browse collection descriptions.
2. **Log in** using the Log In button (top right corner), or  **Apply for Access** from a collection's overview tab. This opens Google Sign-In — use a Google-enabled email address (see note below).
3. **Open any collection tile.** This is where the application starts. 
4. **Locate the Access section** on the right side of the collection page, and select **Apply for Access** and log in with a google-enabled email, if not already done in Step 2. 
5. **Complete the form** with your name, institution, and intended use (see guidance below), then select **Submit**.
6. **Wait for review.** This typically takes about **5 business days**. You'll receive an email either confirming access or explaining why the application wasn't approved.

!!! note "Google-enabled email required"
    You'll need a Google-enabled email address to apply — if your institutional email isn't already Google-enabled, follow the *Learn How* directions on the Passport Login Screen. 

## Writing a strong intended use statement

Give reviewers enough context to evaluate your request — briefly describe the background and goals of your planned analysis rather than a generic statement like "for research purposes."

**Strong statements tend to:**

- Name the specific team(s), collection(s), or data types you intend to use
- Describe the analytical approach and how it connects to your broader research question
- Show that you've already reviewed the relevant data structure or reached out to the contributing team

**Weaker statements tend to:**

- Stay generic ("to study PD," "for my research")
- Not reference any specific collection or data type
- Describe building infrastructure (e.g., a database) rather than a research analysis

See the [ASAP CRN Cloud User Manual](https://storage.googleapis.com/dnastack-assets/explorer/asap-public-assets/wayfinding/ASAP-CRN-Cloud-User-Manual.pdf) (PDF) for full worked examples of both.

## What's next

Once your application is approved (usually within about 5 business days):

- **Explore metadata** for any collection directly in the CRN Cloud Explorer.
- **Analyze the data** by continuing to the [Verily Workbench Guide](../workbench/index.md).
