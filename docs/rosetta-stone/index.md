# CRN Cloud Rosetta Stone

The CRN Cloud Rosetta Stone helps users understand how CRN Cloud datasets, collections, and releases connect.

Use this guide to:

- Find dataset, collection, and release records
- Understand how datasets are grouped into collections
- See which releases introduced or updated records
- Connect records to Explorer pages, workspaces, and Learning Lab examples

## How to use this guide

If you are looking for a specific dataset, start with the **Datasets** page.

## Record types

| Record type | What it describes |
|---|---|
| Dataset | A specific CRN Cloud dataset record |
| Collection | A group of related datasets |
| Release | A versioned CRN Cloud release summary |
